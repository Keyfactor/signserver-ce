Accounters

Accounters can be implemented and configured to integrate with for example an external accounting or billing system.

  • NoAccounter
  • Global Config Sample Accounter

The ACCOUNTER Worker property can be set to one of the available Accounter implementations. For more information on this property, see Common Worker Properties.

Property

Description

ACCOUNTER

Specify the fully qualified class name of the Accounter to use. By default, no Accounter is used. 

Example:

ACCOUNTER=org.signserver.server.GlobalConfigSampleAccounter
