Alias Selectors

Use an Alias Selector to control how the key used for signing is selected at run-time based the signing request. For example, it is possible to have keys selected based on the authenticated user for a signing request.

Overview

By default, if no Alias Selector is explicitly configured, it uses a default selector behaving in a backwards-compatible way, using the DEFAULTKEY property of the Crypto Worker being used.

To configure an alternative alias selector, set the ALIASSELECTOR Worker property of the Worker pointing to the class name of an implementation for an Alias Selector to use.

Available Alias Selectors

  • Default Alias Selector
  • Authorized Username Alias Selector
  • Request Metadata Alias Selector
