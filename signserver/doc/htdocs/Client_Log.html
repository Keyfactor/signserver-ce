Client Log

SignServer applications running on the client-side, not deployed to an application server, such as the SignClient and Admin CLI, use the Log4j configuration file conf/log4j.properties for the output.

To change the log level from INFO to DEBUG or TRACE, edit the conf/log4j.properties file according to the following example:

log4j.rootLogger=TRACE, A1
