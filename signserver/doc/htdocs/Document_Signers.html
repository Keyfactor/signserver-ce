Document Signers

The following lists the SignServer document signers and the purpose of each:

Worker

Description

XML Signer

Creates enveloped XML signatures using XMLDSig.

CMS Signer

Signs arbitrary data and produces a CMS (RFC 3852) SignedData structure in binary format.

Extended CMS Signer enterprise

In addition to all the features provided by the regular CMS Signer, has support for timestamping and more.

PDF Signer

Adds digital signatures to PDF documents.

AdES Signer enterprise

Signs PDF and XML documents, as well as CMS signatures of arbitrary data using ETSI formats for advanced electronic signatures (AdES).
