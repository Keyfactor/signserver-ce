SignServer Community 7.3.2 Release Notes

community edition december 2025

The SignServer team is pleased to announce the newest release of our open-source signing software SignServer Community Edition with version 7.3.2.

These release notes cover new SignServer Community features and improvements implemented between SignServer Community 7.1 and SignServer Community 7.3.2.

This community release of SignServer brings expanded REST options and support for WildFly 35. Several CVEs and bugs have also been addressed.

Highlights

REST API Extensions

This release of SignServer includes an enhancement to the REST API that now supports passing files directly for signing. This simplifies integration with CI/CD pipelines, eliminating the need to install SignClient in scenarios where local client installation is inconvenient.

For more information, see REST Interface.

WildFly 35 Support

SignServer now includes support for the WildFly 35 App Server.

Announcements

Security Issues

SignServer 7.3.2 resolves a security issue affecting file enumeration

Keyfactor rates the issue as having a severity level of low with a CVSS score of 2.4. Once 7.3.2 has been generally available across all platforms for at least two weeks, a CVE with the identifier CVE-2025-47220 will be published.

SignServer 7.3.2 resolves a security issue affecting file writing

Keyfactor rates the severity as medium with a CVSS score of CVSS 6.1. Once 7.3.2 has been generally available across all platforms for at least two weeks, a CVE with the identifier CVE-2025-47221 will be published.

SignServer 7.3.2 resolves a security issue affecting class name enumeration

Keyfactor rates the severity as low with a CVSS score of CVSS 2.4. Once 7.3.2 has been generally available across all platforms for at least two weeks, a CVE with the identifier CVE-2025-47222 will be published.

Customers can learn more at support.keyfactor.com.
