Signum Agents

enterprise

You can sign with Signum using any platform-native signing tool that can access certificates stored in SignServer. Signing with platform-native signing tools allows you to:

  • Use familiar signing tools which are broadly supported by your operating system.

  • Streamline signature verification.

  • Eliminate signature formatting issues.

For more information on Signum, see the Signum SaaS Documentation.

Supported Platforms

Signum supports the following platforms:

  • Windows

  • macOS

  • Linux

After successfully authenticating to Signum through the Agents, you have access to certificates allowed by the roles and policies defined in Signum.

For access to the managed API used by Signum to connect to SignServer, there is a managed role option. To check if a managed role is configured, see the Administrators Page.
