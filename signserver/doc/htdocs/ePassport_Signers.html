ePassport Signers

The following signers provide ePassport signing capability:

Worker

Description

MRTD SOD Signer

Creates the Complete Security Object (SOd) for Machine Readable Travel Documents (MRTD) by signing the provided data groups (DGs).

Master List Signer

Produces a signed list of CSCA certificates according to the ICAO specification.
